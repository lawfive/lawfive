## A server in three commands

You need Docker. Everything else is set up in the browser.

```sh
cp .env.example .env         # then set AUTH_SECRET (openssl rand -base64 32)
docker compose up -d         # the server on port 3000, with Postgres beside it
docker compose logs server   # the setup code that the first visit asks for
```

Watches and phones need HTTPS, so a public server also needs [a certificate in front of it](/run/https/). The full walk-through is [Install a server](/run/install/).
