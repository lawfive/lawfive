# Glossary

| Term | Meaning |
|---|---|
| Match | One game between a home and an away team, made of periods. |
| Period | A half, a quarter or an extra-time period (ET1, ET2). The default is 2 × 45 minutes. |
| Match clock | The main clock. It keeps running past the period's length until the referee ends the period, and stops for stoppages only with a clock that stops (TMR-15). |
| Added time | Time played past the period's length, shown as `45:00 +1:12`. |
| Stoppage | A pause in play the referee wants added back as added time. |
| Stoppage clock | Counts up while a stoppage runs and shows the period's total: the added time to signal. |
| Break clock | Times half-time or a halfway break, counting down or up. Stoppages don't affect it. |
| Halfway break | A drinks or cooling break halfway through each regular period: due at 22:30 in a 45-minute half when its time is added on as stoppage, otherwise centered on halfway (2 minutes due at 21:30). It becomes due then, and starts only when the referee accepts it at a natural stoppage. |
| Short name | A team's name on the match screen, up to 4 characters, for example `RIV` for Riverside FC. |
| Kickoff team | The team that kicks off the first period. |
| Shoot-out | Penalty kicks after a drawn match to decide a winner (ET-3). |
| Sin bin | A temporary dismissal for a set time, where a competition uses them (EVT-12). |
| Format | A match's periods, lengths, breaks and the clock's settings, saved in a template or on the match. |
| Assignor | Whoever gives a referee their matches, often through a system like Arbiter. |
| Track | The referee's own GPS and heart rate over a match, from the watch. |
| Slab | The panel style that holds a section's figures, from broadcast graphics (DESIGN.md). |
